# APRS iGate ESP32C3 v0.5

秋葉原技研 / PS Ham-ware。XIAO ESP32C3 + DRA818V、144.640 MHz Bell 202 1200 bps受信専用iGate。
基板のRev0.1表記とファームのv0.5は別です。

## v0.5の追加

- 起動完了から15分ごとにLCDバックライトを自動点灯。
- 先頭画面から3画面を各4秒、2周して約24秒で消灯。
- 短押しによる60秒点灯、起動時点灯、設定AP中の点灯を維持。
- 手動点灯中または設定AP中に15分周期が来ても、その表示や点灯時間を変更しません。次の周期は15分後です。
- millis差分で制御し、受信処理を待たせるdelayは追加しません。

## v0.4から継承

- 自局位置をAPRS-ISへ送信。RF送信は行いません。
- Web画面からアプリケーションファームをOTA更新。
- v0.3のLED周期、v0.2のLCD起動完了表示、FIX5のADC診断・起動対策を継承。
- TCP書き込みは行全体（CRLF込み）の成功時にのみ成功と判定。部分書き込み時は接続を切り、次の行との混在を防ぎます。

## 最初の書き込み（USB）

1. Arduino IDE 2.3.10、ESP32 Core **3.3.12**、ボード **XIAO_ESP32C3**。
2. このフォルダーの `APRS_iGate_C3_Rev0_5.ino` を開きます。すべての `.h` を同じフォルダーに置きます。
3. Flash Size **4MB**、Partition Scheme **Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)**。
4. USB CDC On Boot **Enabled**。通常の更新は全フラッシュ消去を無効にします。
5. USBで書き込み、Web画面がRev0.5になったことを確認します。

v0.2/v0.3にはOTA受信機能がないため、導入にはUSBが必要です。v0.4導入済みでOTAを設定してあれば、v0.5はWeb更新できます。
標準パーティションはapp0/app1各0x140000バイトとotadataを持ちます。
No OTA / Huge APPは使用しないでください。OTAではパーティション表を変更できません。
旧版と同じNVS名前空間・キーを使用し、既存Wi-Fi/APRS設定を読み込みます。
追加項目は初期状態で位置送信OFF、OTAパスワード未設定です。
パーティション構成を変更する前は設定内容を控えてください。

## 初期設定

設定済みなら同じWi-Fiへ接続します。未設定時はAPRS-iGate-XXXX（パスワードaprssetup）に接続し、http://192.168.4.1/ を開きます。
通常はルーターが割り当てた本機IPまたは http://aprs-igate.local/ へアクセスします。

- Callsign-SSID、APRS-IS Passcode、SSID/パスワードを設定。
- 既定サーバーrotate.aprs2.net、ポート14580。
- Gridは従来どおり保存のみ。
- LCDは15分ごとに約24秒（2周）自動点灯。SETUPボタンを離す：短押しLCD点灯60秒、5秒以上15秒未満AP、15秒以上設定消去。

## 位置ビーコン

Web画面で **Latitude / Longitude** に10進度を入力します。北緯・東経は正、南緯・西経は負。
例：`35.1234` / `139.1234`（これは書式例であり、設置場所の座標ではありません）。
**Send own position to APRS-IS** をチェックし、Commentを設定してSave & Reboot。

- APRS-ISのVERIFIED認証後に初回、その後30分ごと。
- 接続が切れた場合は、接続・認証復帰後、期限到来時に送信。再接続ごとの無条件再送はしません。
- 書き込み失敗時は最短60秒後に再試行。
- 自局のコールサインを送信元、パスはTCPIP*のみ。受信RF転送のqAOとは別です。
- `!DDMM.mmNI DDDMM.mmE&`相当の非圧縮位置形式（実際のパケットにこの説明用空白は入りません）。Iオーバーレイのゲートウェイシンボルを使用。
- WebのPosition beacon TCP writesとシリアルの[BEACON]で送信状況を確認。RFのGated件数には含みません。
- TCP書き込み成功はaprs.fiでの表示を保証しません。自局Callsign-SSIDの生パケットと地図で確認してください。

## OTA更新

1. Web設定の **OTA password** に8〜63文字を入力してSave & Reboot。空欄は既存パスワードを保持します。
2. **Wi-Fi firmware update (OTA)** を開きます。ユーザー名 **admin**、設定したパスワード。
3. このプロジェクト・このボード向けにビルドした**アプリ単体の `.bin`**を選択してUpdate。
4. 成功表示後に自動再起動します。15秒程度待って再読み込みし、バージョンと設定を確認。

Arduino IDEで自作する場合は「スケッチ→コンパイルしたバイナリをエクスポート」。
`*.ino.bin`を使用し、`*.merged.bin`、bootloader.bin、partitions.binは使用しません。
このZIPに同梱した `firmware/APRS_iGate_C3_v0.5_OTA.bin` も同じアプリ単体です。
**v0.4以降のOTA導入済み本機はWeb更新可能です。v0.2/v0.3からの導入はUSBです。**

- パスワード未設定時はOTA無効。設定後は設定保存・Web再起動・Web初期化にも同じ認証を要求。
- OTAには起動ごとのランダムトークンを使用。申告サイズと受信サイズの一致、アプリイメージ検証、非稼働スロットの容量を確認してから切り替えます。
- 通信中断・書き込み失敗・検証失敗では成功扱いにせず、自動再起動しません。再試行可能です。
- 更新中は本体への給電を維持してください。ADCは動作を続けますが、フラッシュ書き込みやネットワーク処理で受信・転送パケットが欠落することがあります。
- OTA成功後の新ファームに起動不具合がある場合、自動で旧版に戻す機能はありません。USBで復旧してください。
- 更新通信はHTTPで、LAN内で使う構成です。インターネットへ更新ポートを公開しないでください。
- パスワードを忘れた場合はUSBでの対応または物理SETUP長押しによる設定全消去が必要です。後者はWi-Fi/APRS設定も消えます。

## LED

接続・認証済み：30秒周期の0〜10秒Wi-Fi LED、10〜20秒APRS LED、20〜30秒両方消灯。
Wi-Fi未接続時400msごと、APRS未認証時700msごとに該当LED反転。
復調時はAPRS LEDを100ms消灯。長時間のmillis周回時は点灯位相がリセットされます。
